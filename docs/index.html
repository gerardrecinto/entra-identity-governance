The checks teams skip, written as tests.

Each check rejects a specific bad input, and the test names it.

OIDC and PKCE

RS256 only. Rejects wrong issuer, audience, nonce, tenant, expired tokens, alg none and HS256. PKCE matches the RFC 7636 test vector.

identity/oidc.py

SAML conditions

Issuer, audience and time window, parsed with defusedxml so a DTD attack is refused.

identity/saml.py

Conditional Access lint

MFA for admin roles, legacy auth blocked, break-glass excluded. A report-only policy is not counted as enforced.

identity/ca_lint.py

PIM audit

Reads Graph role schedules and flags permanent Global Admin, Privileged Role Admin and Security Admin assignments.

identity/pim_audit.py

Lifecycle plan

Compares the HR feed with Entra and returns create, move, disable, enable and review. It never deletes.

identity/lifecycle.py

CyberArk and PowerShell

PVWA logon and account onboarding with rotation on, plus Graph PowerShell for standing admins, a report-only MFA policy and stale guests.

identity/cyberark.py, powershell/

What is real, and what is not verified.

Every claim on this page comes from a command that ran. Anything that did not run is listed on the right.

Verified

  • 17 tests pass, including the RFC 7636 PKCE vector, wrong audience, issuer, nonce and tenant, expired, alg none, HS256, and a SAML DTD attack.
  • Conditional Access gaps, the lifecycle plan, PIM filtering, Graph paging and the CyberArk calls run against local stubs. terraform fmt is clean.

Not verified

  • Nothing ran against a real Entra tenant, Graph or CyberArk.
  • The PowerShell scripts were not run, and terraform validate was not run.
  • SAML signature verification is not implemented. Verify the signature first, then run these checks.
  • Entra ID Governance access packages are not covered.

Questions before you try it.

Why only RS256?

Accepting the algorithm named in the token header is how alg none and HS256 confusion attacks work. The validator fixes the algorithm in code.

Why start Conditional Access in report-only?

It shows who would be blocked before anyone is. Both Terraform policies start report-only on purpose.

Does the lifecycle planner delete accounts?

No. A leaver is disabled and reviewed. Deletion is left to Entra's recycle bin.
